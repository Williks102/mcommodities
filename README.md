# Moses Commodities — Homepage

Homepage Next.js + Tailwind prête pour Vercel.

## Installation
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Déploiement Vercel
1. Pousser ce dossier sur GitHub.
2. Importer le dépôt dans Vercel.
3. Framework: Next.js.
4. Build command: `next build`.
5. Deploy.

## À connecter avant production
- Le formulaire de devis est actuellement une démo front-end.
- Brancher le formulaire à un service email/CRM ou une API.
- Remplacer le monogramme `MC` par le vrai logo.
- Remplacer les blocs visuels temporaires par les photos officielles.
- Vérifier et valider tous les chiffres, certifications et coordonnées avant publication.

## Remarque
Les chiffres et informations affichés reprennent les éléments identifiés lors de l'audit et doivent être validés par Moses Commodities avant mise en ligne.
